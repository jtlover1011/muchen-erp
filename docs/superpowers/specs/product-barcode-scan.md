# 商品扫码需求说明

## 目标
新增一级菜单“商品扫码”，允许手机通过摄像头扫描商品条码，并在电脑 ERP 中即时显示扫描结果、匹配现有商品或暂存未匹配条码。

## 第一版流程
- 桌面端在 ERP 的商品扫码页显示配对二维码和扫描记录。
- 手机与电脑连接同一 Wi‑Fi，打开配对页面并授权摄像头。
- 手机扫描条码后通过局域网 HTTPS 上传条码值；电脑端即时收到。
- ERP 按商品档案的条码字段精确匹配。未匹配条码进入待处理状态，可关联已有商品或稍后处理。
- 扫码不自动改库存、订单或商品档案；绑定条码时才更新商品档案。

## 边界
- 第一版仅扫描条码，不做 OCR、图片上传或云端同步。
- 商品条码可空，既有商品记录保持兼容。
- 局域网配对凭证只对当前运行会话有效；后续可替换为远程同步服务。
- 手机摄像头需要可信 HTTPS；若本机无法取得受信任证书，显示清楚的设置步骤，不静默降级成明文网络。
